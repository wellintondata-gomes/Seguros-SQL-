# SeguroSQL

## Sobre o projeto

O SeguroSQL é um case de estudo desenvolvido para praticar SQL e demonstrar habilidades relevantes para uma oportunidade de Desenvolvedor SQL Júnior.

## Objetivos

- Praticar consultas SQL e relacionamentos entre tabelas.
- Investigar inconsistências nos dados.
- Desenvolver o raciocínio analítico aplicado a problemas de dados.
- Documentar as decisões técnicas e a evolução da solução.

## Tecnologias

- SQL;
- MYSQL workbench.

## Status

**Em desenvolvimento.**

O projeto está sendo construído por etapas. A estrutura, as consultas e a documentação serão atualizadas conforme o avanço do estudo.
